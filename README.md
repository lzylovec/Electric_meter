# 电价分档计算系统（Next.js 同域版）

## 功能概述
- 管理员上传含 24 小时用电量的文件（.xlsx/.xls/.csv）
- 输入“期望总收入（元）”
- 系统按小时分档：高电量→高电价，中电量→中电价，低电量→低电价
- 自动求解三档电价，使总收入严格等于期望值
- 展示结果表格与图表（柱状：用电量 MWh；折线：电价 元/MWh）
- 支持公司选择器：汇总(全部) 与 指定公司单独计算

## 运行环境
- Node.js 18+（建议 LTS）
- npm 9+

## 开发运行
- 安装依赖：
  - `cd server`
  - `npm install`
- 启动开发服务器：
  - `npm run dev`
  - 访问 `http://localhost:3000/`
- 如需修改端口：
  - 开发：`npm run dev -- -p 4000`
  - 生产：`npm run start -- -p 4000`

## 生产运行
- 构建：`npm run build`
- 启动：`npm run start`
- 默认端口：`3000`

## 文件模板规范
- 支持 `.xlsx/.xls/.csv`
- 取第一个工作表（Excel）或整表（CSV）
- 最右侧连续 24 列为 `1点`～`24点` 用电量列，单位为 MWh
- 第 1 行推荐为表头；第 2 行开始每行一个公司/设备
- 非数字内容会被忽略；空行不参与汇总
- 左侧可放“公司名称”“行业”等信息；不要在 24 列小时之后继续放数值列

## 分档与电价计算
- 分档：按每小时总电量从高到低排序，前 8 小时“高”，中间 8 小时“中”，后 8 小时“低”
- 权重：低=1，中=1.5，高=2
- 令缩放系数 `k = 期望总收入 ÷ Σ(电量×权重)`
  - 低档电价 = `k × 1`
  - 中档电价 = `k × 1.5`
  - 高档电价 = `k × 2`
- 每小时电价为该小时所属档位单价；保证 `Σ(电量×小时电价) = 期望总收入`
- 单位：电量 MWh，电价 元/MWh，收入 元

## 界面使用
- 上传/拖拽文件到上传区域，文件名会显示
- 输入“期望总收入（元）”，点击“计算”
- 公司选择器：
  - 汇总(全部)：按所有公司逐行累加后的 24 小时总电量
  - 指定公司：只用该公司的 24 小时用电量进行分档与计算
- 结果区：三档电价、每小时电价与收入、合计收入；图表双轴展示

## 接口说明（同域）
- 上传解析：`POST /api/upload`
  - 请求：`multipart/form-data` 字段 `file`
  - 响应：
    - `200 OK`：`{ filename, sums: number[24], companies: { name: string, values: number[24] }[] }`
    - `400`：`{ error: 'Parse failed' | 'No file' }`
    - `500`：`{ error: string }`
- 解析逻辑：Excel 使用 `xlsx` 库，CSV 以逗号/Tab/分号分隔；去除首列 BOM 防乱码

## 目录结构
- 页面：`pages/index.jsx`
- 样式：`pages/index.module.css`
- 全局：`styles/globals.css`（在 `pages/_app.jsx` 引入）
- 接口：`pages/api/upload.js`
- 配置：`next.config.mjs`
- 包管理：`package.json`

## 常见问题
- Excel 库在浏览器受限：页面会改用同域接口解析；若仍失败，请把文件另存为 `.csv`
- 公司名称乱码：CSV 使用 UTF-8；已处理 BOM `\ufeff`；公司名来自首列
- 端口修改：开发 `npm run dev -- -p 4000`；生产 `npm run start -- -p 4000`
